# Argon

[![Build Argon](https://github.com/Loopfade/argon/actions/workflows/build.yml/badge.svg?branch=main)](https://github.com/Loopfade/argon/actions/workflows/build.yml)

Argon — Android-браузер на базе [Titanium](https://github.com/jqssun/android-titanium-browser) и Chromium с поддержкой расширений и ограниченным доверием к встроенному российскому корневому УЦ.

## Реализовано

- Поддержка расширений Chromium, включая Manifest V2.
- Встроенный российский корневой УЦ с базовым ограничением доверия доменами `.ru`, `.рф` / `.xn--p1ai` и `.su`.
- Дополнительная проверка политики во встроенном верификаторе Chromium: доверие привязано к точному DER-корню, IP SAN запрещены, существующие ограничения не ослабляются.
- Пользовательский список дополнительных DNS-доменов в **Настройки → Конфиденциальность и безопасность → Сертификаты Argon**:
  - добавление и удаление записей;
  - хранение в Chromium PrefService;
  - нормализация регистра, завершающей точки и IDN;
  - запрет IP-адресов, wildcard-записей и публичных суффиксов вроде `.com`, `.net` и `.org`;
  - применение только к явно добавленному домену и его поддоменам.
- Автоматические проверки генератора патча, ограничений доверия и пользовательского списка доменов.


## Сборка и проверка

Сборка доступна [локально на Debian](BUILDING.md) или через **Actions → Build Argon → Run workflow**. Один запуск собирает одну архитектуру; по умолчанию это `arm64`. Для полной локальной подготовки требуется не менее 100 GiB свободного места.

GitHub-сборка использует один runner с подготовленным образом `ghcr.io/loopfade/argon-build`, закреплённым по digest. Изменения подготовленных исходников сначала требуют нового образа; последующее обновление digest в workflow запускает APK-сборку. Перед прогревом проверяются соответствие исходников образу и инструменты подписи.

Результаты компиляции сохраняются через `ccache` и GitHub Actions Cache. Предусмотрено до 20 шагов по 20 минут, но шестичасовой лимит job имеет приоритет: прогрев останавливается раньше, резервируя примерно час на непрерывное завершение сборки и 30 минут на сохранение результатов. Линковка и другие операции вне `ccache` не переносятся между runner. Предыдущие архивы удаляются только после подтверждения нового архива через GitHub API. При исчерпании времени допускается до 10 автоматических продолжений той же архитектуры; ошибки компиляции и ранний код 137 не считаются штатным таймаутом.

Push в `main` собирается с постоянной release-подписью из GitHub Secrets; pull request используют временную тестовую подпись. Ручной запуск по умолчанию также выбирает `release`.

Подробные сценарии проверки описаны в [VALIDATION.md](VALIDATION.md).
