# Проверка логики домашней страницы

Исходный аудит: main `4a06ae6cef49397655bf71c28d2dbc61d632b90d`
и промежуточный PR #82 `624f4717bf0297922c7f6ccf0f64ada229f7049e`.
Ниже — итог исправлений в PR #82. Сценарии проверяются на production HTML/JS
в Chromium; сетевой и нативный транспорт подменяются только в соответствующих
тестах. Это не испытание APK на Android-устройстве.

| Найденное несоответствие | Реализованное поведение |
| --- | --- |
| Лишняя «Готово» при просмотре папки | Кнопка убрана; закрытие крестиком, снаружи или Escape |
| После отмены переноса исчезает «Изменить папку» | Действия папки пересоздаются для актуального режима |
| Сохранение/отмена изменения ярлыка закрывает исходную папку | Возврат в исходную папку; при явном изменении расположения — в папку назначения |
| При переносе нельзя прямо выбрать другую папку | «Выбрать папку» открывает список папок и корневое избранное |
| Подсказка предлагает вкладывать папку в папку | Отдельная подсказка: папки располагаются только в избранном |
| При создании папки подсказка «Название сайта» | Подсказка меняется на «Название папки» |
| Свой поисковик нельзя изменить/удалить; одинаковые адреса разрешены | Управление записями, сохранение ID, запрет повторного URL; удаление выбранной записи переключает на Google |
| Смена темы во второй вкладке теряет черновик и выключает редактирование | Тема обновляется с сохранением формы, ввода и режима |
| Повреждённый PNG заменяет прежнюю свою иконку | Декодирование до замены; ошибка сохраняет прежнюю иконку и блокирует некорректный кандидат |
| Экспорт повреждённого хранилища выдаёт пустое состояние за копию | Обычный экспорт недоступен; отдельное сохранение исходного текста |
| hostname:port без схемы отвергается в редакторе | Принимается как HTTPS, как и при поиске |
| Первое «Готово» после ручного процента только сохраняет число | Сохранение при blur не блокирует исходное нажатие: окно закрывается с первого раза |
| Нажатие снаружи теряет ввод в форме | Формы ярлыка и поисковика сохраняются до явного закрытия/отмены/сохранения |
| Четыре кнопки тем занимают верхнюю панель | Одна кнопка со значком выбранного режима раскрывает список |

## Переносы и ручной размер

Проверяются перенос в папку, извлечение в избранное, перенос между папками
через выбор назначения и редактор, изменение позиции и отмена переноса.
Сохраняются ID, название, полный URL и своя иконка. Папки не вкладываются.

Третий размер **Вручную** принимает целое число **50–200%**. Проверяются
границы и ошибки ввода, предпросмотр, узкий экран 320 px, папки, перезапуск,
последний процент при переключении размеров и первое «Готово».
Скачанная сразу после ввода копия содержит последний процент.

Формат копии и schemaVersion сохранены. Копии без новых полей восстанавливают
готовый размер и фон темы. Прежний код читает новую копию с готовым размером,
игнорируя дополнительные настройки; пересохранение прежней сборкой
отбрасывает неизвестные ей поля.

## Завершённый выбор фона

Добавлены экран своей картинки PNG/JPG/WebP и фотографий Bing, применение,
удаление фона и скачивание JPEG. Изображение хранится локально вместе
с авторством Bing и входит в резервную копию.

UI-проверки покрывают три формата, повреждённый/слишком большой файл,
ошибку и повторную загрузку списка Bing, авторство, запрет скачивания (`wp: false`),
переход на меньшую версию при ограничении размера, скачивание без изменения
настроек, экраны 320/1024 px, отмену запоздавших загрузок, восстановление
скачанной копии и повторное открытие без сетевого запроса. Открытие настроек
и запуск страницы сами по себе не запрашивают Bing.

## Границы проверки

- DOM-сценарии: `tests/homepage/ui-check.mjs`, включая новые
  `regressions-ui-check.mjs` и `backgrounds-ui-check.mjs`.
- Транспорт поисковика: `native-ui-check.mjs` проверяет первый готовый кадр
  после декодирования фона и установки темы, отклонение изменения браузером,
  повторное сохранение, политики и удаление выбранной записи.
- Ресурсы: генерируемый C++-заголовок компилируется целиком, включая фон;
  длина разделителя raw string проверяется при генерации.
- Полная компиляция Chromium/APK, Android-скачивание и жесты на устройстве
  требуют отдельного прогона. Нативные механизмы выхода, защиты от мерцания
  и фонового воспроизведения в этой доработке не меняются.
