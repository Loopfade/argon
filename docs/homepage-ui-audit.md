# Проверка логики домашней страницы

База проверки: `main`, `4a06ae6cef49397655bf71c28d2dbc61d632b90d`.
Сценарии воспроизведены на production HTML/JS в Chromium, с тестовыми ярлыками.
Правки ниже пока не внесены: это результаты для обсуждения.

| Сценарий | Что происходит | Предлагаемое поведение |
| --- | --- | --- |
| Открыть папку → ярлык → Переместить → Отмена переноса | Данные сохраняются, но кнопка «Изменить папку» исчезает до повторного открытия папки | Восстанавливать все действия обычного режима редактирования |
| Открыть папку → ярлык → Изменить → Отмена или Сохранить | Диалог папки тоже закрывается; пользователь возвращается к корневому избранному | Возвращать пользователя в исходную папку |
| Перемещать ярлык между папками через «Переместить» | Внутри папки доступны только «В избранное» и отмена. Другая папка недоступна за модальным окном | Показывать выбор папки назначения. Сейчас прямой путь доступен через Изменить → Расположение |
| Переместить саму папку | Подсказка обещает «На папку — перенести внутрь», но папки не вкладываются: меняется порядок в корне | Подсказка должна учитывать тип перемещаемого элемента |
| Добавить в избранное → Папка | В поле названия остаётся подсказка «Название сайта» | Показывать «Название папки» |
| Добавить свой поисковик | На странице есть выбор и добавление, но нет удаления или изменения созданной записи | Предусмотреть управление своими поисковиками |

Отдельно подтверждена ранее найденная лишняя кнопка «Готово» при обычном
просмотре папки: она дублирует закрытие крестиком.

## Проверенные переносы

- Из корневого избранного в папку через Переместить → нажатие на папку.
- Из папки в избранное через Переместить → В избранное.
- Между папками через Изменить → Расположение.
- Отмена переноса внутри папки.

Во всех этих сценариях сохранены ID ярлыка, название, полный URL с параметрами
и своя встроенная иконка. Дублирования и потери ярлыка не обнаружено.
Проверка не заменяет испытание жестов на Android-устройстве.

## Ручной размер

В рабочей ветке добавлен третий вариант «Вручную», ввод 50–200%, предпросмотр,
проверка диапазона, сохранение последнего ручного значения, резервная копия
и восстановление. Проверены узкий экран 320 px, папки, перезапуск страницы,
старые копии и чтение новой копии точным кодом прежнего main.

## Фон страницы — промежуточный этап

Подготовлены обработка метаданных Bing, загрузка выбранной фотографии через
существующий ограниченный транспорт WebUI, подготовка изображения и формат
хранения фона в резервной копии. Добавлены проверки данных, авторства,
адресов Bing и совместимости формата. Новый модуль включён в ресурсы APK.

Ещё не завершены экран выбора своего фона/Bing в настройках, применение фона
на странице, кнопка скачивания и полный UI-сценарий восстановления фона.
Черновик PR не следует считать готовой реализацией этой части.
