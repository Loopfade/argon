# Закладки на главной

Список сайтов на встроенной главной берётся из штатного `BookmarkModel` профиля.
Сохранение сайта звёздочкой, изменение названия, адреса, порядка или папки и
удаление на штатном экране отражаются в открытых домашних вкладках. Отдельная
команда «Добавить на главную Argon» больше не добавляется в меню.

На главной непосредственно показаны мобильные закладки выбранного хранилища;
другие непустые корневые папки сохраняют свои границы. Вложенные папки открываются
последовательно, с возвратом к родительской. **Управлять закладками** открывает
существующий экран браузера. Главная показывает HTTP(S)-ссылки; остальные типы
закладок остаются доступны на штатном экране.

## Перенос прежних ярлыков

При первом подключении переносятся сохранённые сайты и папки главной. Проверка
одинаковых полных адресов охватывает весь штатный список. Уже существующие
закладки сохраняют название, папку и хранилище. Новые записи добавляются в
мобильные закладки, без удаления или перемещения прежних записей браузера.

Пользовательские иконки остаются в настройках страницы, отдельно от адресов и
иерархии. **Настроить → Иконки закладок** включает выбор значка для ссылки;
долгое нажатие на ссылку также открывает редактор иконки. Название и адрес в нём
показываются только для чтения. Обычные favicon читаются через `chrome://favicon2`
из кэша профиля, без обращения к сайтам или серверу favicon при открытии главной.

Исходное дерево ярлыков сохраняется в неактивной страховочной копии:
`BookmarkModel` записывает изменения на диск асинхронно. Изображения из этой копии
используются по ссылкам внутри настроек, без второго сохранения больших data URL.
Копия не участвует в рабочем списке и не возвращает удалённые закладки
автоматически. В **Перенос данных → Копия прежних ярлыков** можно явно добавить
её содержимое обратно, с предварительным просмотром и проверкой повторов.

Ошибка импорта или локальной записи не удаляет исходные ярлыки. При запрете
редактирования закладок политикой перенос не выполняется, а прежние ссылки
остаются видимыми до успешного переноса.

## Резервная копия

JSON-копия Argon включает текущие веб-закладки, полные пути папок, оформление,
свои иконки и страховочную копию прежних ярлыков. При восстановлении настройки
страницы заменяются, а закладки добавляются в браузер без удаления существующих.
Режим восстановления сохраняет одинаковые адреса в разных папках; повторный
импорт одинакового названия и адреса в одну папку не создаёт ещё одну запись.
Иконки сопоставляются с восстановленными закладками по адресу и пути, поскольку
числовые ID могут отличаться в другом профиле.

Старые копии с локальными ярлыками читаются и переносятся в штатные закладки.
Версия локальных настроек остаётся 2; прежние сборки игнорируют новые поля.
После переноса прежняя сборка может показывать пустую локальную сетку, но сами
сайты остаются в штатных закладках и в страховочной копии новой сборки.

В одном представлении отображаются первые 200 записей папки. Остальные доступны
через штатный экран. Снимок для WebUI ограничен 20 000 узлами и глубиной 64;
если он неполный, экспорт такой копии не выполняется.

## Проверки

`browser-bookmarks.test.mjs` проверяет уведомления, запоздавшие ответы, вложенные
папки, запрет редактирования, ошибку импорта, формат копий, ссылки на сохранённые
иконки и обращение только к локальному кэшу favicon.

`browser-bookmarks-ui-check.mjs` выполняет интерфейс на ширине 320 px с адаптером
BookmarkModel: перенос, переименование, удаление, навигация по папкам, редактор
иконки и восстановление с другими ID. Отдельная C++-проверка исполняет настоящий
фильтр ресурсов с фрагментом URL. CI проверяет Android-графы и компилирует новый
`argon_bookmarks_handler.o`; браузерный адаптер не заменяет эту компиляцию и
проверку APK на устройстве.
